HOW TO READ THE ATLAS

The library, at declaration level.

Every authored definition and statement in the machine library, recursive RamLang source language, certified perfect-hash dictionary, export tools, and checks is included, along with private helpers and unnamed examples. Definitions include types, structures, instances, and predicates. Statements include theorems and example proofs.

Dependencies come from references in Lean’s elaborated types and definition or proof bodies. Constructors, fields, recursors, and generated helpers are grouped into their owning declaration. Lean, Std, and Mathlib internals are omitted.

The graph shows elaborated references, not every name that occurs in tactic text. An arrow means “is used by”; it does not imply that a dependency is logically indispensable. Natural-language descriptions are explanatory; the Lean source is authoritative.

Use Entire library for the complete diagram, or Neighborhood for direct dependencies and users of the selected entry. Search filters the index. Kind and module filters also restrict the diagram; hidden neighbors are still available in the details panel.

Source links open a line-numbered snapshot of the exact .lean files used to build this atlas. Every source page also offers the original file for download.
